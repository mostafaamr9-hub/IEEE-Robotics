IEEE MSA STUDENT BRANCH • EGYPT

October University for Modern Sciences and Arts

The IEEE MSA Student Branch at October University for Modern Sciences and Arts (MSA University) in 6th of October City, Egypt, operates under the IEEE Egypt Section to bridge academic theory and practical engineering. It empowers future engineers through hands-on technical tracks in robotics, embedded systems, electronics, and software development, alongside leadership training, hackathons, and local IEEE competitions.

Pin information

Select a labeled Arduino pin to learn its purpose.

Common Arduino Uno pins

D0–D13

Digital input/output. D0 and D1 are also used for serial communication.

PWM ~3, 5, 6, 9, 10, 11

Can output a PWM signal for brightness or motor-driver control.

A0–A5

Analog input pins for reading variable sensor voltages.

5V / 3.3V

Power outputs. Check your module's voltage requirements.

GND

Ground reference and return path for the circuit.

VIN

External input voltage to the board's power circuit.
